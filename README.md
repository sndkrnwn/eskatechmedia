# eskatechmedia - Vite + React.js

Project konversi dari halaman HTML statis **eskatechmedia** (Konsultan IT & Jasa Pembuatan Website) ke arsitektur **Vite + React.js** dengan **Tailwind CSS**.

## Cara Menjalankan Project

1. Buka terminal pada folder proyek ini.
2. Install dependensi:
   ```bash
   npm install
   ```
3. Jalankan development server:
   ```bash
   npm run dev
   ```
4. Buka URL lokal yang muncul (biasanya `http://localhost:5173`).
5. Build untuk produksi:
   ```bash
   npm run build
   ```
